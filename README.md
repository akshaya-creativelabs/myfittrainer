# MyFitTrainer V2.10

## Update
Replace `index.html`, `manifest.json`, `sw.js`, and `README.md` in the root of the existing GitHub repository, then commit the changes and wait for GitHub Pages to publish.

## Changes in V2.10
- Updates the exercise graph vertical axis to use adaptive, easy-to-read intervals (including 5-unit steps when appropriate) and ensure at least five tick labels when the data range allows.
- Retains subtle horizontal reference lines, exercise demonstrations, corrected exercise history, collapsible history controls, and calendar styling from V2.9.

## Data safety
The app continues to use the existing localStorage key `myfittrainer_v1`. Do not clear Safari website data when updating.

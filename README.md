# MyFitTrainer V2.8

## Update
1. Replace `index.html`, `manifest.json`, `sw.js`, and `README.md` in the repository root with these files.
2. Commit the changes and wait for GitHub Pages to publish.
3. Open https://akshaya-creativelabs.github.io/myfittrainer/?v=28 and confirm the header says V2.8.
4. Close and reopen the Home Screen app if needed.

## V2.8 change
- In the workout calendar, if today has a completed session, the cell is blue with an orange border. If today's session is not completed, the cell remains orange. Other calendar colours and behavior are unchanged.
- Retains the V2.7 collapsible Exercise History and Session History.
- Preserves the existing `myfittrainer_v1` local storage key. Do not clear website data or delete the Home Screen shortcut.

# MyFitTrainer V2.2

Update to the existing GitHub Pages app by replacing `index.html`, `manifest.json`, `sw.js`, and `README.md` in the repository root.

V2.2 changes: compact five-button exercise toolbar; timer and skip-rest control alongside the exercise name; per-set delete; warm-up sets inserted at the top; optional weight for bodyweight/plank exercises (defaults to 0); session completion after saving activities when all exercise sets are complete; session duration in minutes and view/delete icon controls in Session History; smaller icon-only edit/delete controls; timer audio context unlock attempted from user interaction.

The app retains the existing `myfittrainer_v1` localStorage key. Do not clear website data during update.

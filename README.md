# MyFitTrainer V2.7

## Update
1. Replace `index.html`, `manifest.json`, `sw.js`, and `README.md` in the repository root with these files.
2. Commit the changes and wait for GitHub Pages to publish.
3. Open https://akshaya-creativelabs.github.io/myfittrainer/?v=27 and confirm the header says V2.7.
4. Close and reopen the Home Screen app if needed.

## V2.7 changes
- Exercise History entries are hidden until “Show entries” is tapped. The graph remains visible.
- Session History shows the latest three sessions first, with a control to reveal older sessions or show fewer.
- Today is highlighted orange in the workout calendar, even when a workout was completed today.
- Preserves the existing `myfittrainer_v1` local storage key. Do not clear website data or delete the Home Screen shortcut.

# MyFitTrainer V3.2

## Update
Replace `index.html`, `manifest.json`, `sw.js`, and `README.md` in the root of the existing GitHub repository, then commit the changes and wait for GitHub Pages to publish.

## Changes in V3.2
- Graph-point popups now dismiss when the user taps anywhere else on the page.
- Vertical-axis labels are whole numbers, with one-unit intervals for smaller ranges and sensible integer intervals for wider ranges.
- Retains the larger touch targets, exercise-history reconstruction, animated exercise cues, collapsible history controls, and calendar styling.

## Data safety
The app continues to use the existing localStorage key `myfittrainer_v1`. Do not clear Safari website data when updating.
